🛡️ RUANG 1 — SUPER SECURE — PANTAU KEAMANAN + KESEHATAN BADAN!

Super Secure = Bio Health Room + IR 7 Detik + CCTV AI + Gas + Panas + Udara. Pantau orang + ruangan, biar aman + sehat.


Contoh Nyata Super Secure:
• Ibu Ani jatuh di kamar → Gerak-gerik badan detek jatuh → Alarm bunyi → Teknisi + keluarga dikabari.
• Anak kejang → Gerak badan kejang terdetek → Alarm.
• Orang mondar-mandir depan ruko jam 2 pagi → Gerak mencurigakan → CCTV AI rekam + alarm.

OEE Super Secure: Availability = sensor online / total waktu. Performance = deteksi gerak < 2 detik, gas < 5 detik. Quality = akurasi deteksi, rasio false alarm.

🔴 RUANG 2 — SUPER INFRARED — PANTAU KEMATANGAN & CAHAYA!

Super Infrared = MLX90640 + TCS34725. Pantau panas infrared + warna cahaya, untuk toko, pasar, buah, lampu.


Contoh Nyata Super Infrared:
• Kematangan Buah: Pisang kulit hijau → belum matang. Pisang kulit kuning bintik coklat → sudah matang. TCS34725 baca warna kulitnya.
• Kalibrasi Lampu: Lampu toko terlalu putih / terlalu kuning → TCS34725 baca suhu warnanya, lampu disesuaikan biar enak dilihat.
• Kalibrasi Layar: Layar HP terlalu terang → disesuaikan biar mata tidak capek.

OEE Super Infrared: Availability = sensor aktif, tidak terhalang debu. Performance = baca < 3 detik, stabil 3 kali berturut-turut. Quality = kesesuaian antara bacaan sensor dan pengamatan visual.

🧪 Bio Health Room — Teori Tingkat Kebersihan Ruangan

Level 0 — Bersih: Tidak ada bau, tidak ada debu terlihat, sirkulasi baik.
Level 1 — Kotor Ringan: Debu tipis, bau ringan yang hilang setelah ventilasi.
Level 2 — Kotor Berat: Bau menyengat, lantai lengket, debu tebal, ventilasi buruk. Perlu tindakan pembersihan.
Level 3 — Tidak Layak: Sarang tikus, sisa makanan membusuk, jamur, bau menyengat tidak hilang. Risiko kesehatan.

Cara kita menilai: Kesesuaian antara bacaan sensor dan pengamatan manusia. Kalau sensor bilang bau menyengat tapi manusia tidak mencium apa-apa, dicatat sebagai belum terverifikasi, bukan langsung disimpulkan.

Mapping ini spesifik, terkoordinasi, jelas, detail alamat dan keberadaan terdeteksi aktif bila terhubung dan sensor, sehingga terpantau, terkendali, dan bisa maintenance sebagai layanan purna jual.
Setiap titik menunjukkan: Alamat detail + GPS + Status Terhubung (Aktif / Tidak Aktif) + Status Sensor + Hasil Test Multimeter + Teknisi Terdekat + Jadwal Maintenance Purna Jual.

Alat Test Yang Kita Pakai:
• Multimeter Tester: Cek tegangan ESP32 (3.3V / 5V), arus, kontinuitas kabel. Kalau tegangan turun, daya tidak stabil, sensor bisa salah baca.
• Tester Sinyal WiFi: Cek kekuatan sinyal di lokasi alat. Kalau sinyal lemah, data bisa telat.
• Tester Sensor: Cek apakah sensor masih merespons jika diberi rangsangan test.
• Tester Baterai / Daya: Cek apakah baterai / adaptor masih layak.

🔮 Prediksi — Skenario Utama, Alternatif, Invalidasi, Tingkat Keyakinan

Prediksi bukan ramalan. Prediksi adalah skenario yang bisa diuji.

Skenario Utama: Jika sensor tetap aktif dan maintenance berjalan, maka observasi akan stabil.
Skenario Alternatif: Jika sensor kotor atau tegangan turun, maka bacaan bisa menyimpang, perlu verifikasi ulang dengan alat test.
Level Invalidasi: Jika setelah dibersihkan dan diganti kapasitor sensor masih menunjukkan anomali, maka kesimpulan sebelumnya tidak berlaku, perlu observasi ulang.
Tingkat Keyakinan: Tinggi jika 3 kali pembacaan berturut-turut konsisten dan sesuai pengamatan manusia. Rendah jika hanya 1 kali pembacaan dan tidak sesuai pengamatan.
